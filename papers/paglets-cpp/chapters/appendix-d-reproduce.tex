\subsection{Source versions and full implementations}

The software studied here is the C++ branch of
\paglets{}~\cite{pagletsCpp}, using library revision \code{024709697b33} and
WAMR~2.4.5. Source links name the full library commit so their content
does not change as the branch advances. This snapshot contains the
implementation described here; the earlier software release,
\code{cpp-v0.2.0}, does not contain all of these features and fixes.
Each experiment's records identify its own source revision and
executables. Links to current code do not imply that earlier measurements
were rerun with that code.

\subsection{Reproduction instructions and scope}

From \code{cpp/}, configure, build and test with the matching CMake preset:
\code{macos-arm64}, \code{linux-gcc16} or \code{windows-mingw-gcc16}.
The build requires GCC~16 with reflection and a WASI guest toolchain;
the documentation gives exact platform instructions. \code{ctest} runs
tests inside the host and in workers, plus configured command-line,
sandbox, package and documentation checks. Saved results identify the
source, modules, executables, compiler and configuration used.

The physical benchmark script selects \code{move} and \code{jobs} tests
and controls image sizes, repetition counts and integer workloads.
Its header lists the options. It currently assumes directly reachable
Linux remote hosts; Windows correctness tests are separate.
\code{live\_move.json} covers all 48 combinations of host pair, image
size and cache condition. Raw samples and executable identities are
retained in \sourcefile{planning/validation/cpp-three-host-20261015.json}{the test record}.
The \code{chronicle\_live.sh} script applies its failure schedule and
collects protocol traces and the sink result.

Run \code{paglets-protocol-check} with
\code{-{}-suite full -{}-simulate -{}-seeds 10000} for the twelve model
worlds and timed simulations. The
\sourcefile{docs/results/zombie_protocol.json}{recorded protocol results}
state the platform, build and date for each case. \code{--trace SEED}
selects a timed trace; violations of model properties are reported as
shortest step sequences leading to the failure. A search that stops
before its requested coverage is complete fails the check.

\code{paglets-docs-sync} regenerates marked excerpts and selected result
tables. Its check fails if a generated block no longer matches its source.
The paper's Makefile invokes \code{latexmk}; numerical claims in the prose
are checked separately against the records. Building the PDF does not
rerun the experiments.
