\subsection{Interfaces and source artifacts}\label{sec:tools}

A module can include a machine-readable interface description in a
WebAssembly custom section, protected by the module hash. The build
combines message types derived from schemas with message names,
summaries and examples. It rejects incompatible data structures and
invalid values. Native services produce descriptions in the same format.
A shared client uses them for both command-line and browser interfaces;
the host still checks every operation's permissions. These interfaces
help users work with the system but add no recovery guarantees.

The full ABI, SDK and usage instructions are on the
\href{https://cklukas.github.io/paglets/cpp/}{documentation site}.
Appendix~\ref{app:reproduce} links complete source files, raw measurements
and reproduction scripts. The paper includes only the implementation
fragments needed to explain a mechanism. An automated check ensures that
each generated excerpt still matches its marked source region.
