\paglets{}/cpp moves agents by capturing WebAssembly state between
handler calls. The implementation combines memory capture with
host-managed permissions, destination preparation and endpoints that
remain usable after a move. Separate compute jobs allow CPU-specific
execution without making active job stacks part of the mobile state.
The replicated-agent protocol uses the same transition function in the
library, model checker and timed simulator; physical tests exercise its
host integration. The experiments demonstrate operation on the tested
hosts and identify the costs of capture and restoration, as well as
limits imposed by failure assumptions. An open research question is
when moving stateful agents provides a measurable advantage over keeping
computation on fixed hosts, under comparable workloads and failures.
